# BetTrack M1 (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ส่งมอบ BetTrack เวอร์ชันใช้งานได้จริง ได้แก่ calculator, ปุ่ม Win/Lose, history (แก้/ลบ/undo/export), sessions, backup, dashboard พื้นฐาน และ persistence ใน localStorage พร้อม tests และ CI

**Architecture:** Next.js App Router แบบ static export เป็น client-only ทั้งหมด เก็บเฉพาะข้อมูลดิบ (rounds) ใน Zustand + localStorage ตัวเลขทุกตัว (balance, stats) คำนวณใหม่จาก pure function ใน `lib/calculations/` ด้วย decimal.js ส่วน UI อ่านจาก store ผ่าน hook ที่ memoize

**Tech Stack:** Next.js 16, React 19, TypeScript strict, Tailwind CSS 4, shadcn/ui, Lucide, Motion, Zustand 5, decimal.js 10, zod 4, sonner, Vitest 4 + jsdom, pnpm, GitHub Actions

**Spec:** `PLAN.md` (root) — อ่านคู่กับแผนนี้เสมอ โดยเฉพาะ §3 (data model และกติกา), §8 (UX) และ §10 (testing)
