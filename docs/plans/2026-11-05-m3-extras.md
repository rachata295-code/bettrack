### Task 4: Monte Carlo engine + worker

**Files:**
- Create: `lib/calculations/montecarlo.ts`, `lib/workers/montecarlo.worker.ts`, `tests/lib/montecarlo.test.ts`

**Interfaces:**
```ts
export function mulberry32(seed: number): () => number; // [0,1)
export type SimBet = { mode: 'fixed'; amount: number } | { mode: 'percent'; percent: number; minBet: number };
export interface SimInput { p: number; multiplier: number; start: number; bet: SimBet; rounds: number /* 1–10000 */; runs: number /* 1–10000 */; seed: number; precision: number }
export interface SimResult { ruinProb: number; medianFinal: number; probAboveStart: number; meanFinal: number;
  bands: { round: number; p10: number; p50: number; p90: number }[] /* ≤ 201 จุด: round 0 และจุดเว้นระยะเท่ากันถึง rounds */ }
export function validateSimInput(raw: Record<string, string>): { ok: true; value: SimInput } | { ok: false; errors: Record<string, string> };
export function simulate(input: SimInput, hooks?: { onProgress?: (done: number) => void; shouldStop?: () => boolean }): SimResult | null; // null = ถูกยกเลิก
```
- กติกาต่อรอบ: bet = fixed amount หรือ max(minBet, floor(balance×percent/100, precision)); ถ้า bet > balance (หรือ balance < minBet ในโหมด %) → หมดตัว หยุดเล่น run นั้น (balance คงที่ถึงจบ); ชนะ balance += bet×(m−1) แพ้ balance −= bet; ปัดที่ precision หลังแต่ละรอบ (`Math.round(x*10^precision)/10^precision`)
- หน่วยความจำ: เก็บ balance ณ จุด band เท่านั้น (Float64Array(runs × points)); percentile ด้วยการ sort ต่อจุด
- Worker: รับ `{ type: 'run', input }`, ส่ง `{ type: 'progress', done }` ทุก ~2% และ `{ type: 'result', result }`; ยกเลิกด้วย `worker.terminate()` จากฝั่ง UI
- [ ] **Step 1: test ที่ fail**
```ts

expect(simulate({ ...base, p: 1 })).toMatchObject({ ruinProb: 0, medianFinal: 30, probAboveStart: 1 });
```
